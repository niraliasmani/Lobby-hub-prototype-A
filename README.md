# Lobby Hub 2.0 — Prototype A

Interactive prototype of the updated **Lobby Hub** (the "Hub / Updated" frame from the *Lobby of the Future* Figma file), built as a native-iOS-style experience for **iPad mini (744 × 1133)**.

**Live prototype:** https://niraliasmani.github.io/Lobby-hub-prototype-A/

## What's in it

- **Hub** – itinerary, guest list with search, Select All / Deselect All, per-guest selection and the bottom action bar (Boarding Pass, Add Bags, Print Tags, Continue).
- **Guest cards** – show only what each guest has (Documents, SSRs, Bags, Lap Infant, Rebooking). Tapping the card header opens Profile, the seat tile opens Seats, and **+ Add** opens the add menu.
- **Detail screens** – Profile (Personal Info, Atmos Rewards, Known Traveler, Redress), Documents with Doc-V, Special Service Requests (WCHR, AVIH), Bags and Bag Scan, Seats, Lap Infant, Remarks / Booking Info, VCR & Fees.
- **Bulk Add Bags** – opened only from the bottom action bar: Group Assign, per-guest bag types with steppers, Special Items menu and a running total.
- **Check-in** – Continue opens Summary & Payment; paying checks in the selected guests. Boarding Pass supports Print and Send.

A side panel lists the usability-test tasks, with a **Restart prototype** button. Tap any non-interactive area to flash the hotspots.

## Running it

It's a single self-contained file (`index.html`), with no build step. Open it in a browser, or on an iPad mini open the live link in Safari and use **Add to Home Screen** to run it full screen.

Data in the prototype is sample content for testing; prices for bag types are placeholders.
